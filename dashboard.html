Import records, choose what to preserve, and check which questions the retained evidence can answer.

Import supported records

Use SCOPE JSON or exported Sysmon XML that contains process creation or network connection events. Import each event type separately when its required fields differ.

Open Add records →

Choose what to preserve

Each selected rule must hold for every record in the batch. SCOPE compares candidate sizes with the same codec and selects the smallest one that preserves those rules.

Open Results →

Interpret investigation answers

No matches means no retained records match. Not enough information means SCOPE could not check a required detail.

Open Ask questions →

Review storage measurements

Live Results compares complete encoded documents and shows SQLite allocation separately. Benchmarks use recorded synthetic workloads and report observed evidence checks and timings.
